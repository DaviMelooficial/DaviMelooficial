## Selected projects

### [Marketing Analytics Engineering Pipeline](https://github.com/DaviMelooficial/marketing-analytics-engineering-pipeline)

End-to-end analytics engineering pipeline that transforms campaign, cost and revenue data into an analytics-ready mart for BI consumption.

**Highlights**
- S3 as raw landing zone.
- Snowflake as analytical warehouse.
- dbt models organized into staging, intermediate and mart layers.
- Final table with KPIs such as profit, CTR, CPC, ROAS, RPM and pages per session.

**Stack:** Python, AWS S3, Snowflake, dbt, SQL.

---

### [AWS S3 API Ingestion Pipeline](https://github.com/DaviMelooficial/aws-s3-api-ingestion-pipeline)

Lightweight ingestion pipeline that extracts JSON data from a public API and stores it in Amazon S3 using a partitioned raw-layer structure.

**Highlights**
- API extraction with timeout and HTTP validation.
- S3 raw-layer organization.
- Centralized logging with rotating files.
- Foundation for Snowflake + dbt modeling.

**Stack:** Python, Requests, boto3, AWS S3, Snowflake, dbt.

---

### [ELT API Brasil.io](https://github.com/DaviMelooficial/elt_api_brasil.io)

ELT pipeline for Brazilian federal government spending data using a Medallion Architecture approach.

**Highlights**
- Raw → Bronze → Silver → Gold architecture.
- Apache Airflow orchestration with Docker.
- DuckDB analytical layer.
- Automated validation and analytical KPIs in the Gold layer.

**Stack:** Python, Airflow, Docker, DuckDB, Parquet, Pandas.

---

### [Supplier ESG Intelligence](https://github.com/DaviMelooficial/ESG-ML-SOLUTION)

Analytical and machine learning solution for supplier ESG risk, maturity and criticality classification.

**Highlights**
- Full-stack analytical application.
- Machine learning experiments tracked with MLflow.
- FastAPI backend and PostgreSQL database.
- Dockerized environment for reproducibility.

**Stack:** Python, FastAPI, PostgreSQL, scikit-learn, MLflow, Docker, Next.js.
